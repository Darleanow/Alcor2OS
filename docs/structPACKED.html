Detailed Description

Linear framebuffer description (fixed layout for syscall ABI).

POSIX directory entry returned by getdents(2).

ext2 directory entry structure.

ext2 inode structure.

Block group descriptor.

ext2 superblock structure.

Physical Region Descriptor for DMA.

Saved interrupt frame (pushed by ISR stub + CPU).

IDT pointer (for LIDT instruction).

IDT entry (16 bytes on x86_64).

Task State Segment (x86_64 format).

GDT pointer structure (for LGDT instruction).

16-byte GDT entry for the TSS (x86_64).

8-byte GDT entry for code/data segments.

Located at byte 1024 from the start of the partition.

Describes one block group in the filesystem.

Contains file metadata and block pointers.

Variable-length entry in directory blocks.

Variable-length; d_name immediately follows the fixed fields. d_reclen is rounded up to an 8-byte boundary.
