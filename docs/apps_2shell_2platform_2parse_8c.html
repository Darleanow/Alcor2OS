◆ is_input_complete()

static int is_input_complete ( const char *  buf)
static

True if buf parses as a complete vega statement.

Mirrors the lexer's quoting rules — single quotes are literal, double quotes recognise \" \\ \$ as escapes. Brace counting is suppressed inside either quote. One heredoc per command. A negative brace depth (} without {) is treated as complete: let the parser surface the error rather than wedge the REPL.

Parameters
bufNUL-terminated input buffer.
Returns
Non-zero if the input is complete, 0 if more input is needed.

Drive sh_read_line in a loop until buf forms a complete statement (closed quotes, balanced braces, finished heredoc).

Read input lines into buf until they form a complete statement.

The primary prompt (with decorative header) is used for the first line and the │ » continuation prompt for subsequent lines. Each successful line is appended to buf followed by \n.

Parameters

Returns
