Detailed Description

Single-line interactive editor: cursor motion, history navigation, tab completion display, UTF-8-aware glyph counting.

Reads input from an off-screen ncurses pad (not stdscr) so the keypad escape parser is available without triggering an implicit wrefresh that would clobber our write()-based output.

Read one input line with editing, history, and tab completion.

Read one logical input line, with history navigation, tab completion, and UTF-8-aware cursor movement.

Blocks until the user presses Enter, Ctrl-C, Ctrl-D, or Ctrl-L. Cursor motion (←/→, Home, End, Backspace, Delete) and history navigation (↑/↓) are handled in-place via redraw_line.

Parameters
bufCaller-owned buffer; receives a NUL-terminated line.
capCapacity of buf in bytes.
promptPrompt string (may include ANSI escapes).
Returns
Byte length of the line, RL_EOF (Ctrl-D on empty line), RL_INTERRUPT (Ctrl-C), or RL_CLEAR (Ctrl-L).
