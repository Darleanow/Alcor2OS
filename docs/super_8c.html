Detailed Description

Block-level I/O, superblock + GDT writeback, volume bring-up.

Owns the per-volume state (g_volumes) and the default device pointer (g_default_dev), plus the low-level block read/write primitives every other ext2 module routes through. Mount and init also live here because they are the only callers that touch the raw superblock layout.

Default on-disk inode size for revision-0 ext2 volumes.

Revision 0 has no s_inode_size field; the size is fixed at 128. Revision ≥ 1 reads it from the superblock instead.
