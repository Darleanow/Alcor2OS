Detailed Description

Userland helpers for the Alcor2 custom framebuffer syscalls.

Thin inline wrappers around SYS_ALCOR_FB_INFO and SYS_ALCOR_FB_MMAP. Include this header in userspace programs that need direct framebuffer access (renderers, compositors, graphics demos).

Requires a libc with syscall() — musl is the tested implementation. Compile with SSE enabled for x86_64 float ABI compatibility with stb / FreeType code.
