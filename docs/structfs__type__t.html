void *(* fs_type_t::mount) (const char *source, u32 flags)

Mount a volume and return its private state.

Called by vfs_mount. The returned pointer becomes fs_data and is forwarded to every fs_ops_t callback for this mount.

Parameters
sourceDevice path or special string (driver-defined).
flagsMount flags (currently always 0).
Returns
Volume-private data pointer on success, NULL on failure.
