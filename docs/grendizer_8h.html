Detailed Description

Single-header CLI parsing library for Alcor2 userland.

Grendizer is a zero-dependency, freestanding-compatible C library that provides structured command-line argument parsing and optional subcommand routing. It is designed for the Alcor2 userland and compiled against musl.

Design principles
  • Declarative, zero-allocation API: all state lives in caller-owned structs.
  • Options are declared with a sentinel-terminated array of gr_opt.
  • Short options (-x ) and long options (--name ) are supported.
  • Value-taking options accept --name VALUE or --name=VALUE .
  • Short flags may be clustered: -xvz expands to -x -v -z .
  • A bare -- ends option scanning; everything after becomes positional.
  • Built-in --help / -h handler calls gr_usage and returns GR_HELP when neither is defined by the caller.
  • Positional arguments are collected into a slice; the original argv array is reordered in-place so argv[1..positional_count] form a contiguous block on return.
Subcommands
Declare a sentinel-terminated gr_cmd array and call gr_dispatch. Subcommands may be nested arbitrarily deep. help and --help are handled automatically at every level.
Quick start
#include <grendizer.h>
int main(int argc, char **argv) {
int verbose = 0;
const char *output = NULL;
gr_opt opts[] = {
GR_FLAG('v', "verbose", &verbose, "Enable verbose output"),
GR_STR ('o', "output", &output, "PATH","Write output to PATH"),
GR_END
};
gr_spec spec = { "mytool", "mytool [options] <input>", opts, NULL };
gr_rest rest;
int rc = gr_parse(&spec, argc, argv, &rest, NULL, 0);
if (rc != GR_OK) return rc == GR_HELP ? 0 : 1;
// rest.argv[0..rest.argc-1] = positional args
}

Enumeration Type Documentation

◆ gr_kind

enum gr_kind

Kind of a single gr_opt entry.

Select the appropriate kind when declaring options with gr_opt or the helper macros (GR_FLAG, GR_STR, ...).

Enumerator
GR_KIND_END 

Sentinel: terminates a gr_opt array. Use GR_END .

GR_KIND_FLAG 

Boolean presence flag. storage must point to an int ; it is set to 1 on the first occurrence. Repeated occurrences are silently accepted and keep the value at 1 .

GR_KIND_COUNT 

Accumulating counter. storage must point to an int that is incremented once per occurrence. Useful for verbosity levels (-v -v -v or -vvv ).

GR_KIND_STR 

String value. storage must point to a const char* ; it is made to point into the original argv slice (no heap).

GR_KIND_INT 

Signed decimal integer. storage must point to a long .

GR_KIND_UINT 

Unsigned decimal integer. storage must point to an unsigned long . A leading minus sign is rejected.

GR_KIND_FLOAT 

Floating-point value. storage must point to a double . Supported: -1.5 , 3.14e+2 (hand-rolled; no strtod dependency).

int gr_parse ( const gr_spec *  spec,
int  argc,

gr_rest *  rest,
char *  errbuf,
size_t  errcap 
)

Parse command-line arguments according to spec.

On success the function returns GR_OK and populates rest with the slice of positional arguments found after option processing.

Built-in help is printed and GR_HELP is returned when --help or -h is encountered and the caller has not defined an option with that name in spec.options .

On error the function writes a NUL-terminated human-readable message into errbuf (if non-NULL and errcap > 0) and returns GR_ERR . The message is always terminated correctly; it is truncated with "..." when it exceeds the buffer capacity.
