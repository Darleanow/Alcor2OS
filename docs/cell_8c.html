Detailed Description

Cell-to-pixel rendering for the framebuffer console.

Turns one fb_cell_t into a rectangle of framebuffer pixels via the userspace atlas (32-bpp fast path or per-pixel for other depths) or the compiled-in CP437 bitmap fallback. Underline drawing piggybacks on the same routine — it is part of the cell's visual contract, not a separate pass.
