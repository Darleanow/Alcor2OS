Detailed Description

Filesystem syscalls: open, close, stat, seek, rename, chdir, …

Every entry point validates user pointers through the VMM before touching them, then delegates to the VFS layer. The stat_buf layout follows the x86-64 POSIX ABI used by stat / fstat / lstat.
