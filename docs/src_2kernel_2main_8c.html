Detailed Description

Kernel entry point and bring-up sequence.

Typical order: console → PMM (Limine map) → VMM (HHDM) → GDT/IDT → PIC/PIT → kernel heap → ATA disk → ext2 volume on / → VFS → keyboard → syscall MSRs → scheduler → first user program (shell or binary from module).
