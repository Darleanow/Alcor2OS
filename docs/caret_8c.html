Detailed Description

Text caret (blinking block cursor) tracker for the framebuffer console.

Named caret_* (not cursor_*) to keep it unambiguously distinct from the software mouse cursor that lives in fb_console_mouse.c. Owns the "last drawn at (x, y)" tracker so its statics never leak out via headers — the few cross-file consumers that need to invalidate or query it go through the exported helpers below.

Paint the caret at the current fb_ctx.cx/cy by drawing the cell with fg/bg swapped. Records the position so a later caret_erase can undo the inversion.

Saves/restores the cell's attributes around the inverted blit so the cell grid keeps the "real" glyph state — that way the next blit of the same cell from any path (scroll, atlas reload, scrollback exit) does the right thing without a separate "is this the caret" branch.

int s_drawn_x = -1
static

Cell currently displaying the inverted-block cursor.

-1 means "no cursor on screen right now" — caret_erase short-circuits on that sentinel. Tracked separately from the logical cursor (fb_ctx.cx / fb_ctx.cy) so a single moved-cursor frame only re-blits the previous and new cells instead of redrawing the row.
