Detailed Description

Compiler driver installed as /bin/cc, /bin/clang, /bin/c++ and /usr/bin/cxx.

Thin wrapper around /bin/clang.real. Derives C/C++ mode from argv[0] and input file extensions; injects all include and link search paths explicitly so Clang needs no auto-detection. argv[0] forwarded to clang.real must be an absolute path — LLVM’s getMainExecutable() has no procfs fallback.
