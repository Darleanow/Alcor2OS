Detailed Description

Shell entry point: bring up ncurses input, atlas, termios snapshot, source /home/.vconf, then run the REPL forever (read a complete vega statement, hand it to vega_run, restart).

The actual line editor lives in platform/edit.c, history in platform/history.c, prompt rendering in platform/prompt.c, the brace/quote/heredoc-aware statement reader in platform/parse.c, and the config-file sourcing in platform/vconf.c. This file just sequences them.
