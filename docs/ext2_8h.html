Read next directory entry.

Parameters
dirDirectory handle.
entryOutput entry.
Returns
1 if entry read, 0 if end, negative on error.

Read next directory entry.

Walks the directory's data blocks from the start each call, counting non-deleted entries until it reaches index. Linear scan is the correct choice here: dir entries are variable-length, so a "seek to N" is meaningless on disk; the only authoritative way to find entry N is to walk N entries. Callers (readdir loops) just increment index.

Parameters
dirOpen directory handle.
indexZero-based entry index to fetch.
entryOutput entry structure.
Returns
1 if an entry was read, 0 at end, or negative errno on error.

Read symlink target (final path component only). Path is mount-relative (e.g. "bin/clang"), no leading slash.

Target length on success, negative -errno on error.

Read symlink target (final path component only). Path is mount-relative (e.g. "bin/clang"), no leading slash.

Splits the path so the target's containing directory is resolved (not the symlink itself — that would follow it). The final component is then looked up directly, its inode validated as a symlink, and the target read via the shared read_symlink_target so fast/slow link layouts stay in one place.

Parameters
volVolume handle.
pathAbsolute path of the symlink.
bufOutput buffer (no terminating NUL appended).
capCapacity of buf.
Returns
Bytes written, or negative errno (-EINVAL for non-symlinks, -ENAMETOOLONG when the target exceeds cap).

Truncate a file to zero length.

If shrinking past zero, free all data blocks; if extending, simply record the new size — ext2_read returns zeros for unallocated holes, matching POSIX sparse-file semantics. (Future: free blocks beyond the new tail when shrinking to a non-zero size — for now the user payload we care about is "extend to N then write N bytes" which is the lld codepath.)

Parameters
fileOpen file handle.
lengthTarget length in bytes.
Returns
0 on success, negative errno on error.
