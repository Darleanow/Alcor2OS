◆ pci_bar_base64()

u64 pci_bar_base64 ( const pci_device_t *  dev,
int  idx 
)

Resolve the physical base of a BAR, handling 64-bit pairs.

For 64-bit memory BARs, this consumes BAR idx and BAR idx+1. For I/O BARs, returns the I/O port base. Returns 0 if idx is invalid or the BAR is unimplemented.
