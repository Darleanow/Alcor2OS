Detailed Description

vega — Alcor2's shell scripting language. Public entry points.

vega is a from-scratch bash-flavoured shell language with cleaner syntax: brace-delimited control flow, brace string interpolation, and a single canonical form for command substitution. Embedders include this header plus <vega/host.h> (the sh_* interface they must implement).
