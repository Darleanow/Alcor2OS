Detailed Description

No-op sound backend for Alcor2OS.

Alcor2 has no audio hardware driver. All sound and music functions are implemented as empty stubs so the game runs silently without SDL_mixer or any other audio library.

This file replaces doomgeneric/doomgeneric/i_sound.c in the build. Global variables declared extern in i_sound.h are defined here with sensible defaults so they satisfy the linker without side-effects.
