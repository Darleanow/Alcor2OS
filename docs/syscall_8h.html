Detailed Description

x86_64 syscall interface and definitions.

Syscalls use the SYSCALL/SYSRET instructions with System V AMD64 calling convention. Syscall number in RAX, arguments in RDI, RSI, RDX, R10, R8, R9. Return value in RAX. RCX and R11 are clobbered by SYSCALL.
