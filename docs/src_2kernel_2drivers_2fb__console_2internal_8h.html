Detailed Description

Shared state, types, and hot-path primitives for the fb_console module split.

Not part of any public/UAPI surface — purely the contract between the fb_console_*.c source files. Public consumers go through <alcor2/drivers/fb_console.h> instead. Splitting the original 1.8 KLOC monolith required a single source of truth for the shared fb_ctx singleton and the hot blitting helpers; this header is that source.
