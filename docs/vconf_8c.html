Detailed Description

Source /home/.vconf (or any path) as a vega script on startup.

Equivalent of .bashrc — runs any vega language feature (let, if, fn, pipes, builtins like kbd). Stdout is redirected to /dev/null for the duration so the script's commands don't print to the user's console.

void sh_source_vconf ( const char *  path)

Read path and execute its content via vega_run.

Source path as a vega script with stdout redirected to /dev/null.

Stdout is dup2'd to /dev/null for the duration so commands in the script (e.g. echo) don't bleed onto the user's prompt. The original stdout is restored on return. Silently no-ops when the file doesn't exist.

Parameters
pathAbsolute path to the config file (e.g. "/home/.vconf").
