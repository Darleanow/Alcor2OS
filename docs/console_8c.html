Detailed Description

Boot/panic logger on the linear framebuffer.

Minimal text output for the kernel: an 8x16 ISO Latin-1 bitmap font, cursor advance, scroll, plus \n / \r / \b / \t. No escape sequences, no SGR, no charset switching, no UTF-8 multibyte. Anything richer (ncurses, ANSI colors, line drawing, Fira) lives in the user-space terminal at user/shell/platform/fb_tty.c.

Reached from kernel boot prints (main.c, sched, mm, ...) and from sys_write whenever a process writes to stdout/stderr without an OFT entry — which after the shell takes over is essentially never.

◆ DEBUGCON_PORT

#define DEBUGCON_PORT   0xE9

Sideband debug-console port.

Every byte written here lands in whatever backend the host has wired up (a developer terminal during emulation, nothing when nobody is listening). Always safe to enable — unattached hosts silently discard the writes.
