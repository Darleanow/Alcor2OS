Detailed Description

8x16 monospace bitmap atlases used by the kernel boot logger.

font_latin1 is the ISO Latin-1 atlas (kbd lat1-16.psfu, code points U+0000-U+00FF) and drives console.c. font_cp437 is the legacy VGA box-drawing atlas, kept around as a fallback option but unused now that the user-facing terminal (shell fb_tty) renders box drawing through Fira
