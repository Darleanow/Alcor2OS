Detailed Description

Kernel mouse broker.

Owns the cursor position and the event ring served via /dev/mouse. The producer is the PS/2 mouse IRQ handler (via mouse_post_event); consumers are syscalls that drain via mouse_read_block. Single-waiter model: one process can sleep on the ring; additional pollers get -EAGAIN.

Post one movement/button report into the broker.

Called from the mouse IRQ handler (interrupts already off). Updates the cursor (clamped to the screen in free mode, pinned to centre in relative mode), enqueues the event, and wakes any blocked reader.

Parameters
dxX delta (right positive).
dyY delta (down positive).
dwheelWheel delta (up positive).
buttonsButton bitmask (see ALCOR2_MOUSE_BTN_*).
