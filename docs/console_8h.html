Detailed Description

Kernel boot/panic logger on the linear framebuffer.

Plain 8x16 ISO Latin-1 bitmap text with cursor advance, scroll, and the \n / \r / \b / \t controls. No escape sequences, no SGR, no charset switching, no UTF-8 multibyte — strictly for kernel messages before the user-space terminal takes over.

The user-facing terminal emulator (Fira via FreeType + HarfBuzz, full ANSI/CSI, DEC line drawing, 256-color SGR) lives in user/shell/platform/fb_tty.c.
