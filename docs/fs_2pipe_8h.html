Detailed Description

Kernel pipe object interface shared by the VFS and syscall layers.

A pipe is an anonymous, unidirectional byte channel backed by a fixed-size ring buffer. The VFS stores one opaque pipe pointer per OFT entry and dispatches reads/writes through this interface. The pipe object itself is allocated by pipe_alloc_obj and freed when both ends are released.

Release the read end of a pipe.
