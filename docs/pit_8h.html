Detailed Description

8253/8254 PIT (Programmable Interval Timer) driver.

Configures the PIT for periodic timer interrupts and tracks system ticks.

Macro Definition Documentation

◆ ALCOR2_IOC_TIMER_FAST

#define ALCOR2_IOC_TIMER_FAST   ((1U << 30) | (0x54U << 8) | 1U | (4U << 16))

ioctl(0, ALCOR2_IOC_TIMER_FAST, &uint32_t on): vote for the elevated rate (on != 0) or release the vote (on == 0). Refcounted and auto-released on process exit. Mirrors musl ‘_IOW('T’, 1, uint32_t)`.
