Detailed Description

Descriptor for a single syscall mapping.

Handler signature is invariant six u64-in / u64-out (System V order: RDI, RSI, RDX, R10, R8, R9). No nargs field — every entry accepts the full register window and ignores unused slots via (void)aN.
