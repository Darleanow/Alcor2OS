Detailed Description

Select Graphic Rendition (SGR) handling — CSI m parsing.

SGR is the largest CSI subset by parameter count: bold/italic/underline attrs, 8/16/256/truecolour fg+bg, and their resets. Lives in its own file because csi_sgr fans out to four kinds of param consumer (reset, attr, basic colour, extended colour) and each is non-trivial on its own.
