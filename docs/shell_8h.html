Detailed Description

Shell-internal helpers (sh_*) used by main.c, builtins.c, and the shell's platform layer. main.c packages a subset of these into a vega_host_ops_t to register with libvega.

◆ rl_result_t

enum rl_result_t

Non-byte-length return values from sh_read_line.

Encoded as negative int so sh_read_line can return either a positive byte count (line length) or one of these control codes from the same function signature.

Enumerator
RL_EOF 

Ctrl-D on an empty line.

RL_INTERRUPT 

Ctrl-C — in-progress line is discarded.

RL_CLEAR 

Ctrl-L — caller should clear the screen.

Compute completions for prefix.

When is_command is true, matches against shell builtins and executables in /init, /bin, /usr/bin. Otherwise matches filesystem entries under the directory implied by prefix (or CWD when prefix has no slash). Directories get a trailing / in their entry name.

Parameters
prefixPartial word typed so far.
is_commandtrue for command-position completion (first word on the line), false for path completion.
outResult accumulator; zeroed on entry, filled with candidates and the longest common prefix on return.

void sh_source_vconf ( const char *  path)

Source path as a vega script with stdout redirected to /dev/null.

Acts like .bashrc — silently ignored if path doesn't exist. Restores the original stdout on return.

Parameters
pathAbsolute path to the config file (e.g. "/home/.vconf").

Source path as a vega script with stdout redirected to /dev/null.

Stdout is dup2'd to /dev/null for the duration so commands in the script (e.g. echo) don't bleed onto the user's prompt. The original stdout is restored on return. Silently no-ops when the file doesn't exist.
