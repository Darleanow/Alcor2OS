void gdt_init ( void  )

Initialize the Global Descriptor Table and load the TSS.

Initialize the GDT and load the TSS.

Sets up kernel code/data segments, user code/data segments (with proper ordering for SYSRET compatibility), and the Task State Segment. Loads the GDT and switches to the new segments.
