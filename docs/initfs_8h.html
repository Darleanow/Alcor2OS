Detailed Description

Read-only, buffer-backed filesystem populated from Limine modules.

initfs ships the small userland utilities (/bin) inside the boot ISO so they survive a wipe-free reboot — the persistent ext2 disk only needs to hold user data (/home, /tmp, /etc) and the heavier apps/ binaries that live under /usr/bin.

The filesystem is flat (no subdirectories) and read-only. Each file's payload is a pointer into a Limine module buffer; nothing is copied.
