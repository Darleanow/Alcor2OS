Detailed Description

Process lifecycle, scheduling, fork/exec/exit, and context switching.

Each process owns a kernel stack, a user address space (cr3), and a saved user context. The round-robin scheduler runs at syscall boundaries; the PIT timer sets a preemption flag that is checked on every syscall return.

Allocate a free process slot from the process table.

The slot is fully zeroed before any non-zero defaults are installed. Going through kzero rather than field-by-field resets means a stale sig_actions handler, sig_pending bit, etc. from a previously reaped occupant cannot survive into the new process — and any future field added to proc_t inherits the right "blank" default for free.

◆ proc_exec_replace_image()

i64 proc_exec_replace_image ( proc_t *  p,
const char *  name,
i64  elf_fd,
char *const  argv[],
char *const  envp[] 
)

POSIX-style exec: replace p's user image with the ELF read from elf_fd. Tears down the current user mappings, loads the new ELF, and builds a fresh user stack with argv.

On success p->user_rip / p->user_rsp point at the new entry; the caller is responsible for updating its in-flight syscall frame so the sysret return path lands in the new image. On catastrophic failure the old image has already been destroyed and the process can no longer continue — the caller should proc_exit.

Does not vfs_close elf_fd; the syscall wrapper closes scratch fds after success when appropriate (see sys_execve).

Returns
0 on success, negative -errno on failure.
