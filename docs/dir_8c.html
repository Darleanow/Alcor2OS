Detailed Description

High-level directory operations — readdir, mkdir, unlink, rmdir.

Sits on top of the on-disk dirent primitives in dir_entry.c (dir_find_entry / dir_add_entry / dir_remove_entry / dir_is_empty) and the path/inode/block-allocation layers. The separation keeps the rec_len byte arithmetic in one file so the VFS- facing ops here read as policy (link-count rules, free-on-zero-links, empty-on-rmdir) rather than dirent layout details.

Read the entry at index from an open directory.

Read next directory entry.

Walks the directory's data blocks from the start each call, counting non-deleted entries until it reaches index. Linear scan is the correct choice here: dir entries are variable-length, so a "seek to N" is meaningless on disk; the only authoritative way to find entry N is to walk N entries. Callers (readdir loops) just increment index.

Parameters
dirOpen directory handle.
indexZero-based entry index to fetch.
entryOutput entry structure.
Returns
1 if an entry was read, 0 at end, or negative errno on error.
