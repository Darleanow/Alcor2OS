typedef struct syscall_frame syscall_frame_t

Saved registers on syscall entry (x86_64 System V layout).

The ASM syscall stub pushes registers in this exact order so the dispatcher receives a pointer to this struct. Offsets are verified by _Static_assert.

◆ cpu_init_pat()

void cpu_init_pat ( void  )

Initialize the Page Attribute Table MSR.

Programs IA32_PAT so that PWT=1 (VMM_PWT / VMM_WC) selects Write-Combining. Must be called before any WC framebuffer mapping is established.

Initialize the Page Attribute Table MSR.

Only entry 4 deviates from the x86 reset defaults; the framebuffer mapping uses it (via VMM_WC) for fast, coalesced stores. Entries are encoded one memory type per byte: WB=6, WC=1, WP=5, UC-=7, UC=0.
