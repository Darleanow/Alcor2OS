Detailed Description

Minimal scheduler API for drivers and low-level kernel code.

Drivers must not include proc.h (which pulls in VFS, termios, etc.). This header exposes only what hardware interrupt handlers need.

Run the scheduler; switch to the next ready process.

Schedule the next process to run.

Performs simple round-robin scheduling. Searches for the next PROC_STATE_READY process starting from the current process. If no ready process is found, halts the CPU.
