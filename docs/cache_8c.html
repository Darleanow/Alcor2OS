Detailed Description

Single-block scratch pool for one-off ext2 metadata reads.

Not a block-content cache — the underlying blockdev (ATA driver) owns its own sector cache. This pool just sidesteps kmalloc churn for the burst of one-block metadata reads that every fs operation issues (superblock, group descriptors, inode table, bitmap, indirect block).

u8 * cache_get_block ( u32  size)

Borrow a one-block scratch buffer from the pool.

Acquire a single-block scratch buffer from the static pool.

Oversized requests bypass the pool so the fixed-size slots stay reusable for the common case (4K or smaller blocks). Pool exhaustion silently falls back to kmalloc — caller's contract is "you got a buffer", not "you got a pooled buffer".

Parameters
sizeRequested block size in bytes.
Returns
Pointer to a buffer of at least size bytes; never NULL unless the kmalloc fallback fails.
