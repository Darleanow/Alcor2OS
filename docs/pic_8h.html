void pic_init ( void  )

Initialize and remap the PIC.

Initialize and remap the PIC.

Remaps the PIC IRQs from 0-15 to 32-47 to avoid conflicts with CPU exceptions. Initially masks all IRQs (they must be explicitly unmasked).
