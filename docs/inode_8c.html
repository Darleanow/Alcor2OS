Detailed Description

On-disk inode read + write.

Two functions, almost-symmetric. They share the same block-locate math (group → inode table → offset) because the inode lives in a packed variable-stride table; centralising here keeps the math in exactly one place per direction.

Load on-disk inode ino into the caller-provided inode.

Read inode ino from disk into inode.

The inode table is a packed array with stride vol->inode_size, which can exceed sizeof(ext2_inode_t) on newer revisions — so the math uses inode_size for both the per-block count and the offset, and the kmemcpy clips to the in-memory struct size.

Parameters
volSource volume.
inoInode number (1-indexed; 0 is reserved).
inodeOutput struct.
Returns
0 on success, -EINVAL for out-of-range, -ENOMEM / -EIO otherwise.

Persist inode to its on-disk slot for inode number ino.

Persist inode for inode number ino back to disk.

Read-modify-write of the containing block: we read the table block first because the slot is a sub-region inside a shared block (other inodes live alongside it), and overwriting without merge would clobber them.
