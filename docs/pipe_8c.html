Detailed Description

Anonymous pipes backed by a fixed-size ring buffer.

Pipes live in the open file table as VFS_KIND_PIPE_RD / VFS_KIND_PIPE_WR entries; per-process file descriptors point at those entries the same way file fds do. End-of-pipe lifetime is reference-counted via the OFT refcount, so fork-inheritance and dup/dup2 work the same as for files.
