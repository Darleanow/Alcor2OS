Detailed Description

Dirty-cell flush batch + character emission for the framebuffer console.

Two related responsibilities:

  • put_cp_at_cursor — write one codepoint at the cell cursor, mark the cell dirty (in batch mode) or blit it immediately, and advance. Called once per glyph emitted by the ANSI/UTF-8 feeder.
  • flush_batch — turn every cell whose dirty bit is set in the [batch_r0, batch_r1] row range into pixels, in one VRAM pass, using a heap-owned per-row scratch (s_flush_ci) so we can avoid re-resolving the atlas glyph for every scanline of every cell.

void flush_batch ( void  )

Repaint every dirty cell in the [batch_r0, batch_r1] row range in one VRAM pass.

Repaint every dirty cell in the [batch_r0, batch_r1] row range in one VRAM pass, then clear their dirty bits.

Fast path resolves each cell's atlas glyph into the per-row scratch once, then walks scanline-by-scanline so the inner loop is a tight 4-byte fill or alpha-blend. The slow path falls back to blit_cell per cell — that covers 24/16-bpp and the no-atlas state, neither of which is performance critical.

void flush_ci_ensure ( int  cols)

Grow the per-row scratch to hold at least cols entries.

Grow the per-row scratch used by flush_batch to at least cols entries. Called on grid init and whenever a SET_ATLAS reflow widens the grid.

Allocation failure leaves the previous buffer in place: flush_batch tolerates s_flush_ci being NULL but not smaller than the current grid, so retaining the larger old buffer is preferable to shrinking on failure.
