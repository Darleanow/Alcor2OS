Entry point for the rmdir utility.

Parses command-line flags (-p, -v, -n, -c) and removes each specified directory. With -p, ancestor components are removed after the leaf; a non-empty ancestor stops the walk without error. With -c, the directory tree is removed recursively. With -n, a preview of all actions is shown and the user is asked to confirm before any deletion is performed. Exits with status 0 only if every leaf removal succeeded.

Parameters
argcArgument count from the shell.
argvArgument vector from the shell.
Returns
0 on success, 1 if any directory could not be removed.

Remove a directory and optionally its content and ancestor components.

When parents is set, ancestor directories are removed after the leaf; a non-empty ancestor (ENOTEMPTY / EEXIST) stops the walk without error. When content is set, the directory tree is removed recursively.
