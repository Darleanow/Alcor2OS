Detailed Description

Read-only, flat ramfs populated from Limine boot modules.

See include/alcor2/fs/initfs.h. The kernel walks the boot-module list during early init, registers each /boot/bin/ ELF via initfs_register, then mounts the result on /init so the core utilities ride along inside the ISO; the persistent ext2 disk holds everything else.

#define INITFS_ROOT_HANDLE   ((fs_handle_t)(uintptr_t)0x1)

Sentinel handle returned by init_open for the root directory.

Distinct from any heap pointer and from NULL so read/stat handlers can distinguish "this is the root" from "this is a file node" with a pointer compare.
