Detailed Description

Per-cell scratch built by flush_batch before walking scanlines.

Holds everything a single cell's row blit needs so the inner scanline loop never re-touches the fb_cell_t — that loop already runs cell_h times per dirty cell, so any per-cell work paid up-front is amortised.

glyph_base == NULL signals "bg-only" (space, blink-off, or atlas miss): the scanline loop fills the cell width with bg_pk and skips the blend altogether.
