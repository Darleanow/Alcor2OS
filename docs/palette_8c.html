Detailed Description

Catppuccin Mocha ANSI palette and xterm-256 resolution.

The 16-colour tables and the ansi256_to_rgb resolver live together because they share an array index — ansi256_to_rgb falls through to ansi16_fg / ansi16_fg_bright for indices 0..15 instead of duplicating the values. Kept in-kernel rather than pushed to the spazer graphics SDK because the boot-time console must paint before any userspace lib is loaded.

u32 ansi256_to_rgb ( unsigned  idx)

Map an xterm 256-colour index to a 0xRRGGBB triplet.

Resolve an xterm 256-colour palette index to a 0xRRGGBB triplet.

Three slots back-to-back in the palette: 0..15 = base + bright ANSI, 16..231 = the 6x6x6 cube, 232..255 = the 24-step greyscale. Formulas mirror the xterm definitions verbatim so a TUI program sees the same colours it would on real xterm.

Look up one axis (red, green, or blue) of the xterm 6x6x6 cube.

The xterm cube uses non-linear stops {0, 95, 135, 175, 215, 255}; modeled here as "0 for stop 0, else @c XTERM256_CUBE_STOP_1 plus a step per axis tick". Pulled out of ansi256_to_rgb so the cube math reads once instead of three times.

Catppuccin Mocha 16-colour foreground palette.

Catppuccin Mocha 16-colour foreground palette. Indices match SGR 30..37. Defined in palette.c; shared with sgr.c so the SGR handler can resolve colour codes without re-declaring the table.

Indices are the ANSI SGR codes minus the 30 base — slot 0 is SGR 30 (black), slot 7 is SGR 37 (white).
