Detailed Description

PS/2 mouse driver (i8042 second port).

QEMU routes pointer motion to the emulated PS/2 mouse by default, so this is the driver that actually carries the pointer. Decoded 3-byte packets feed the kernel mouse broker via mouse_post_event.

◆ mouse_ps2_irq()

static void mouse_ps2_irq ( u8  irq)
static

IRQ 12 handler: accumulate one mouse packet byte, post on completion.

Reads a single byte and only if the controller tags it AUX. Consuming a keyboard byte here would desync the keyboard stream (dropped make/break codes stick keys). The i8042 raises one IRQ per byte, so one read per call is right.
