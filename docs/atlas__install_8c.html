Detailed Description

Userspace atlas submission pipeline for the framebuffer console.

Implements fb_console_set_atlas and its phases: validate descriptor → mirror user buffers into kernel copies → reflow the cell grid when cell geometry changes → repaint + broadcast SIGWINCH. Lives in its own file because each phase has its own failure mode that needs an unambiguous return path, which crowded api.c when inlined.

Mirror the user-side atlas into kernel-owned buffers and publish every field of meta into fb_ctx.atlas_*.

The copy is what lets the kernel keep rendering after the submitting process munmap's its source — without it, every cell blit would race the unmap. Previous atlas storage is kfree'd here so a reload doesn't leak memory across submissions.

Parameters
metaValidated descriptor.
cp_bytesSize of the codepoint map (from validate_atlas_meta).
Returns
0 on success, -1 if either copy buffer kmalloc failed (state unchanged in that case).

static void reflow_grid_for_atlas ( const fb_console_atlas_t *  meta)
static

Reflow the cell grid when the new atlas's cell size differs from the live one.

No-op when the cell geometry matches what's already on screen (atlas reload with same metrics). On grid resize, the previous cell content is discarded — cell coordinates don't survive a cols/rows change in any well-defined way. On kmalloc failure the existing grid is left in place and the atlas blit clips to the old cell_w/cell_h instead.
