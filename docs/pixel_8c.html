Detailed Description

Raw framebuffer pixel primitives for the fb_console module.

Pure pixel-level access: no awareness of cells, glyphs, or grid. Every higher layer (cell, flush, mouse cursor) routes through these so the per-bpp marshalling lives in exactly one place.

u8 bytes_pp_from_bpp ( u16  bpp)

Translate the framebuffer's bits-per-pixel into bytes-per-pixel.

Map a hardware bpp value (32/24/16) to bytes-per-pixel.

Centralised so every code path that strides through a scanline agrees on the same value; the default falls back to 4 because Limine's preferred format is 32 bpp and assuming it keeps the renderer alive if the bootloader ever reports an unfamiliar mode.

Parameters
bppBits per pixel reported by the framebuffer request.
Returns
Bytes per pixel (1..4 in practice).

Plot one pixel honouring the current framebuffer depth.

Write one pixel of color at (x, y) honouring the framebuffer's current bytes_pp.

Clips silently against (width, height) at the only place where a pixel actually lands so the dozens of callers (atlas glyphs, mouse halo, cell underline) need not each defend against out-of-bounds coordinates. The 32-bpp path forces the alpha byte to opaque so an alpha-aware compositor downstream doesn't see ghost pixels from previous frames.

Parameters
xPixel column.
yPixel row.
color0xRRGGBB; alpha is supplied by the renderer per format.
