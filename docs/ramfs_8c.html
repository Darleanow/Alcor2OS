Standalone ramfs driver for Alcor2.

Implements a simple tree-based in-memory filesystem.

◆ ramfs_chardev_register()

i64 ramfs_chardev_register ( const char *  path,
const ramfs_chardev_ops_t *  ops,
void *  ctx 
)

Register a character device under path inside the ramfs tree.

path is rooted at the ramfs root (which the kernel mounts at /dev), so "/mouse" surfaces as /dev/mouse to userspace. Parent directories must exist. The registered node cannot be removed via unlink / rmdir.

Parameters
pathRamfs-relative path; must start with /.
opsCallback table (pointer must outlive the kernel; statics OK).
ctxOpaque pointer forwarded to each callback.
Returns
0 on success, negative -errno on failure.
