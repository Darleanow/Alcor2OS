Detailed Description

vega user-defined function table.

Stores registered functions keyed by name. Defining a function via the fn name(args) { body } syntax routes through this module — it takes ownership of the name, arg-names array and body AST. Redefining replaces the previous body (the old AST is freed). The table is fixed-size for simplicity; further entries are rejected.
