Detailed Description

Kernel mirror of musl's struct termios.

Layout/size are frozen by the syscall ABI (TCGETS/TCSETS copy 60 bytes verbatim). Adding fields means breaking userspace; instead, store kernel- private TTY state next to the per-proc termios in proc_t.
