Detailed Description

musl-compatible termios blob (60 bytes) for per-process TTY discipline.

Must match musl sizeof(struct termios) on x86_64 and sys_ioctl TCGETS/TCSETS.

◆ ktermios_init_default()

void ktermios_init_default ( k_termios_t *  t)

Reset t to the cooked-TTY defaults a freshly forked PID would expect (ICRNL|ONLCR|CS8|CREAD|CLOCAL|ISIG|ICANON|ECHO|IEXTEN, B38400, the standard control-char table).

Exists so callers do not duplicate the default bit-soup — keeping the initialiser in one place means a future ABI tweak only edits one file.

Parameters
tDestination termios. Caller-owned, no NULL guard (a NULL here is a kernel logic bug — fail fast via crash).
