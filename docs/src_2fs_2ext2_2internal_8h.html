Detailed Description

Shared state, sizing macros, and private helpers for the ext2 module split.

Not part of any public/UAPI surface — purely the contract between the source files under src/fs/ext2/. Public consumers go through <alcor2/fs/ext2.h> instead. Splitting the original 2.7 KLOC monolith required a single source of truth for the shared volume / file pools and the cross-file helpers; this header is that source.
