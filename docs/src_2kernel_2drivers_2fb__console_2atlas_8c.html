Detailed Description

Glyph atlas lookup + meta validation.

Hot side: codepoint → glyph index resolution called per dirty cell during blit_cell_data and flush_batch. Cold side: atlas_meta_is_sane gates a userspace-submitted descriptor before the rest of the kernel trusts its sizes and indices.

u32 atlas_lookup ( u32  cp)

Resolve a Unicode codepoint to its slot in the userspace atlas.

Resolve cp to an atlas glyph slot.

Goes through atlas_fallback when the codepoint is out of range or maps to no glyph, so renderers can always assume "something will be drawn" and never have to special-case a missing glyph in the hot path. The idx sanity check (< atlas_n_glyphs) guards against a corrupt cp_map leaking through the atlas_meta_is_sane gate.

Parameters
cpUnicode codepoint.
Returns
Atlas glyph slot, or ATLAS_NO_GLYPH when no atlas is active.

u16  attr 
)

Resolve to the bold or italic sub-atlas slot when SGR asks for one.

Like atlas_lookup, but follow the bold/italic sub-atlas offset when the requested attribute is set. Single chokepoint for SGR-aware glyph resolution — keeps blit paths from each re-implementing the offset arithmetic.

Centralises the offset-add arithmetic so each blit path doesn't reinvent it (or forget the bounds check). Bold wins over italic when both bits are set: the bold variants are typically more readable, and the parser already accepts that combination silently rather than erroring out.

Parameters
cpUnicode codepoint.
attrCell SGR bits; only FB_ATTR_BOLD and FB_ATTR_ITALIC are consulted.
Returns
Styled slot when available, plain slot when not, ATLAS_NO_GLYPH on miss.

◆ atlas_meta_is_sane()

bool atlas_meta_is_sane ( const fb_console_atlas_t *  meta)

Reject a userspace atlas descriptor whose fields would misbehave inside the renderer.

Reject a userspace atlas descriptor whose sizes/bounds would misbehave inside the renderer.

The kmalloc and per-codepoint walks in fb_console_set_atlas trust every field of meta verbatim once this returns true, so this is the one and only place where an attacker-controlled value gets bounded. Caps are generous (no real font needs anything near them) — the goal is to stop a runaway allocation, not enforce font policy.

Parameters
metaDescriptor copied from userspace.
Returns
true if every field fits the ATLAS_*_MAX caps and stride is within cell_w * max-bytes-per-pixel.
