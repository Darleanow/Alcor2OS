Detailed Description

Compiler ABI built-in shims.

Compilers (like clang and gcc) will occasionally emit calls to standard library functions like memcpy, memset, and memmove, even when compiling with -ffreestanding. This happens for struct copies, aggregate zero-init, and similar compiler-generated code.

This file provides these essential ABI symbols to satisfy the linker (ld.lld -nostdlib), forwarding them to our internal k-variants which are optimized with inline assembly (REP MOVSB / REP STOSB).
