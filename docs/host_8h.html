Detailed Description

libvega embedding interface.

The kernel framebuffer console handles glyph rendering, ANSI parsing, and blink — so libvega doesn't intercept output. The host only needs to provide a handful of things the language itself can't decide:

  • which builtin commands are available in this host (shell has cd/pwd/..., CLI has none).

Everything else (stdout, filesystem queries, etc.) libvega does through plain musl.
