◆ gr_parse()

int gr_parse ( const gr_spec *  spec,
int  argc,
char **  argv,
gr_rest *  rest,
char *  errbuf,
size_t  errcap 
)

Parse command-line arguments according to spec.

On success the function returns GR_OK and populates rest with the slice of positional arguments found after option processing.

Built-in help is printed and GR_HELP is returned when --help or -h is encountered and the caller has not defined an option with that name in spec.options .

On error the function writes a NUL-terminated human-readable message into errbuf (if non-NULL and errcap > 0) and returns GR_ERR . The message is always terminated correctly; it is truncated with "..." when it exceeds the buffer capacity.

Parameters
specParsing specification (non-NULL).
argcmain argc .
argvmain argv ; reordered in place on return.
restFilled with the positional slice (non-NULL).
errbufOptional buffer for error messages.
errcapCapacity of errbuf in bytes, including the NUL terminator.
Returns
GR_OK, GR_HELP, or GR_ERR.
