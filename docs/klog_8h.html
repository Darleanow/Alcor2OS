Detailed Description

Sideband kernel log channel that bypasses the framebuffer.

Writes every byte to I/O port 0xE9. Hosts that sink that port surface the stream to a developer terminal; otherwise the writes are discarded. Use this for high-volume / post-boot debug taps (syscall traces, etc.) that must not touch the framebuffer — the boot logger (console_print) is the wrong channel for those because it would draw over the fb_console terminal owned by user processes.

Supports a small printf subset: s, c, d, u, x, lx, lu, %%. No floats. No width / precision specifiers.
