Detailed Description

Per-driver runtime state for the framebuffer console.

Was an anonymous static struct in the monolithic fb_console.c; lifted to a named typedef + extern singleton when the module was split so the sibling source files could share it without poking into a private symbol. Stays a single instance — there is only one framebuffer.
